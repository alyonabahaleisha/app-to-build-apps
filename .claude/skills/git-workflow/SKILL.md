# Git Workflow Skill

Manages git operations for the agentic ticket execution workflow in the Bluesky Social App.

## Repository Info

- **Root**: project root (where `package.json` and `.git` live)
- **Default branch**: `main`
- **Branch naming**: `agent/<ticket-id>` for agent-created branches

## Branch Operations

### Create feature branch
```bash
git fetch origin main && git checkout -b agent/<ticket-id> origin/main
```

### Verify branch creation
```bash
git branch --show-current
```

### Check for conflicts with base
```bash
git merge-base --is-ancestor origin/main HEAD && echo "up to date" || echo "diverged"
```

## Commit Operations

### Stage and commit
```bash
git add <files> && git commit -m "<type>(<scope>): <description> [<ticket-id>]"
```

### Conventional commit format
```
<type>(<scope>): <description> [<ticket-id>]
```

**Types:**
- `feat` — new feature
- `fix` — bug fix
- `refactor` — code restructuring without behavior change
- `test` — adding or updating tests
- `docs` — documentation changes
- `chore` — build, config, or tooling changes
- `style` — formatting (no code change)

**Examples:**
```
feat(profile): add user metrics display card [CARD-abc123]
fix(feed): resolve crash on empty feed response [CARD-def456]
test(profile): add unit tests for metrics query [CARD-abc123]
refactor(dialog): extract common dialog patterns [CARD-ghi789]
```

### Check commit history
```bash
git log --oneline origin/main..HEAD
```

## Diff Operations

### Files changed vs base
```bash
git diff --name-only origin/main..HEAD
```

### Full diff vs base
```bash
git diff origin/main..HEAD
```

### Stat summary
```bash
git diff --stat origin/main..HEAD
```

## PR Operations

### Push branch to remote
```bash
git push -u origin agent/<ticket-id>
```

### Create PR via gh CLI
```bash
gh pr create \
  --title "<type>(<scope>): <description> [<ticket-id>]" \
  --body "$(cat <<'EOF'
## Ticket
[<ticket-id>](<source_url>)

## Summary
<approach from plan>

## Changes
<bulleted list of files changed>

## Acceptance Criteria Coverage
| AC | Test | Status |
|----|------|--------|
| AC-1 | TestFile#testMethod | PASS |

## Verification Report
- **TypeCheck**: PASS
- **Lint**: PASS (0 new violations)
- **Unit Tests**: PASS (N/N passed)
- **E2E Tests**: PASS / Skipped

## Scope
Files modified: N
All within planned scope: Yes

---
Generated by agentic workflow
Trace ID: <trace_id>
EOF
)" \
  --base main \
  --head agent/<ticket-id>
```

## Safety Rules

### NEVER execute:
- `git push --force` or `git push -f`
- `git reset --hard`
- `git clean -fd`
- `git branch -D`
- `git rebase -i`

### ALWAYS verify before pushing:
1. All commits reference the ticket ID
2. No secrets in the diff
3. Branch name matches `agent/<ticket-id>`
4. Verification passed (verdict = PASS)

## Conflict Resolution

If a rebase or merge produces conflicts:
1. **Do NOT attempt auto-resolution.**
2. Log the conflicting files.
3. Escalate to the coordinator with conflict details.
4. Coordinator decides whether to retry or escalate to human.
